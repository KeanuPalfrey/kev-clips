2. Description of the Service

Kev Clips helps the user create clips from Twitch streams, convert them into vertical 9:16 videos with subtitles and titles, and upload or post those videos to the user's own accounts on third-party platforms, including TikTok, YouTube Shorts, Instagram, Facebook Reels and X.

TikTok features use TikTok for Developers Login Kit and the Content Posting API, with the following scopes:

  • user.info.basic — to display the connected TikTok account name and avatar so the user can confirm the correct account is linked.
  • video.upload — to send a finished video to the user's TikTok drafts or inbox.
  • video.publish — to publish a finished video directly to the user's TikTok account when the user chooses direct post.

The Service runs locally on the user's computer. It does not provide a public website product, a multi-user platform, or hosted accounts.
